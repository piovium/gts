# GTS type-checking benchmark

Measured with Node 26.3.1 and TypeScript 6.0.3 on the 195 GTS files in
`genius-invokation` at `ab1960bd`. Their total source size is 1,251,902 bytes.
The baseline transpiler is GTS `384c9e0`. Both runs use the same TypeScript,
Volar, project options, and dependency sources, with incremental checking off.

With an 8 GiB V8 old-space limit:

| Metric | Baseline | Optimized | Reduction |
| --- | ---: | ---: | ---: |
| Generated TypeScript bytes | 82,675,400 | 50,289,570 | 39.2% |
| TypeScript reported memory | 4,841,860 KiB | 4,110,999 KiB | 15.1% |
| Peak process RSS | 5,656,144 KiB | 4,329,256 KiB | 23.5% |
| Type-checking time | 48.00 s | 38.90 s | 19.0% |
| Total compiler time | 60.94 s | 47.62 s | 21.9% |
| Type instantiations | 9,997,859 | 8,849,363 | 11.5% |

With a 4 GiB old-space limit, the baseline runs out of memory. The optimized
compiler completes checking, with the same diagnostics as the 8 GiB baseline.
A 3 GiB limit is still insufficient. Times and memory usage are individual
measurements and vary with garbage collection; the heap-limit comparison is
separate from the table above.

The production checkout had stale declaration output. The benchmark therefore
used a temporary tsconfig extending `packages/data/tsconfig.json`, with `paths`
pointing `@gi-tcg/core`, `@gi-tcg/core/*`, `@gi-tcg/utils`, and `@gi-tcg/typings`
to their source entries, and `@gi-tcg/gts-runtime` to this repository's runtime
source. Both runs completed with the same 91 diagnostics in dependency sources
and **no GTS diagnostics**. This measures completion of checking, not a clean
exit for the whole production project. No files in the production checkout
were changed.

## Reproduction

Build the local compiler, then use the included script with ordinary tsc
arguments. It also prints the generated byte count, mapping count, and peak
RSS:

```sh
pnpm --filter @gi-tcg/gtsc... build
node --max-old-space-size=8192 packages/tsc/scripts/benchmark.mjs \
  --noEmit --incremental false --extendedDiagnostics --pretty false \
  -p ../genius-invokation/packages/data/tsconfig.json
```

Use the same temporary source-path configuration for both runs if the production
declarations are stale. Compare full diagnostic output, rather than only exit
codes or error counts. Repeat with `--max-old-space-size=4096` to test the memory
limit.

## Semantic checks

`packages/transpiler/__tests__/typing_semantics.test.ts` checks exact inferred
types and mapped diagnostics for Meta rewriting/merging, bindings, overloads,
required and duplicate attributes, Meta-dependent unique keys, union returns,
action contexts, and long diagnostic ranges. The same cases run in editor and
command-line modes. The 36 semantic cases were also run against the baseline
transpiler; the additional test checks preservation of editor completions.

```sh
pnpm vitest --run packages
pnpm --filter @example/local exec vitest --run
```

These pass 125 package tests and the local GTS import test, respectively.
